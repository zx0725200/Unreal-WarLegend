# 방치형 오토 던전 RPG — 기획서 (v0.1)

> 동봉 파일: `밸런스_방치형던전.xlsx` (모든 수치는 이 시트가 정답. 파란색 셀만 바꾸면 전체 자동 재계산)
> 엔진: Unity (간단 구현 목표). 표는 CSV로 export 해서 `Resources` 또는 ScriptableObject로 로드.

---

## 1. 게임 개요

직접 전투하지 않는다. 캐릭터의 **스펙(데미지 / 방어 + 체력)** 으로 던전을 **오토(자동)** 로 돌고,
스펙이 높을수록 **클리어 시간이 단축**된다. 클리어하면 드랍을 얻어 장비를 강화하고, 더 깊은 던전으로 나아간다.

**핵심 동사:** 스펙 올린다 → 던전 시간 줄인다 → 더 깊은 던전 → 더 좋은 드랍.

---

## 2. 핵심 루프

```
던전 선택 → 오토 진행(시간 측정) → 성공/실패 판정 → 드랍 획득
   → 장비 제작/장착 · 특수아이템 누적 · 스킬 진화 → (반복, 다음 던전 해금)
```

- **오토 전투 종료 시** 그동안 획득한 아이템 목록을 모아서 보여준다 (방치 보상 정산 화면).

## 3. 캐릭터 & 장비

- **캐릭터 2명.** 각자 장비/스킬 진화를 따로 가진다.
- **장비 6칸** — 3칸은 데미지, 3칸은 방어+체력.

| 부위 | 스탯 | 분류 |
|---|---|---|
| 무기 | 데미지 | 공격 |
| 보조 | 데미지 | 공격 |
| 모자 | 데미지 | 공격 |
| 방어구 | 방어력 + 체력 | 방어 |
| 기타 | 방어력 + 체력 | 방어 (※ 제작 조건 특수) |
| 벨트 | 방어력 + 체력 | 방어 |

- **특수칸 1칸** — 아르카나 **또는** 어비스 하나만 장착 (4번 항목).

### 장비 티어 스탯 (시트: `장비_티어`)
- 티어 N 1칸 데미지 = `데미지기본(100) × 성장배수(2.5)^(N-1)`
- 방어/체력도 동일 성장배수. 한 부위 풀착 기준 총합은 시트의 `총데미지(3칸)`, `총방어+체력` 열 참조.

---

## 4. 특수아이템 — 아르카나 / 어비스 (시트: `특수아이템_스택`)

- 일반 던전에서 드랍. **아르카나 / 어비스 50:50 랜덤**, **효과는 동일**, 특수칸엔 **하나만 장착**.
- **개수 누적**으로 데미지·경험치 획득량이 **소폭** 상승. 발동 시작 **100개**, 최대 중첩 **4000개**.
- 중첩 구간: **100 / 200 / 300 / 500 / 1000 / 2000 / 4000**

| 보유 개수 | 데미지 배수 | 경험치 배수 |
|---|---|---|
| 100 | ×1.15 | ×1.10 |
| 200 | ×1.22 | ×1.18 |
| 300 | ×1.30 | ×1.28 |
| 500 | ×1.42 | ×1.45 |
| 1000 | ×1.60 | ×1.80 |
| 2000 | ×1.75 | ×2.30 |
| 4000 | ×1.90 | ×3.00 |

> **핵심 게이팅:** 풀스택 데미지 배수 **1.90 < 티어 성장배수 2.50**.
> → 아르카나를 아무리 모아도 **다음 던전의 기본치(다음 티어 장비)** 보다 약하다. 던전 스킵 불가.
> 실제로 "N티어 장비 + 아르카나 풀스택" = 정확히 "N+1 던전 20분 입장선(CPR 1.0)" 이 되도록 맞춰져 있음.

---

## 5. 스킬 진화 (시트: `스킬진화`)

- **보스 던전 3 / 6 / 9** 클리어로 드랍. 캐릭터당 총 **3개**.
- 획득 시 **데미지 강화**. 1개당 ×1.20 (곱연산) → 3개 풀 시 **×1.728**.

| 획득처 | 누적 데미지 배수 |
|---|---|
| 보스 3 | ×1.20 |
| 보스 6 | ×1.44 |
| 보스 9 | ×1.728 |

## 6. 던전 구조 (별개 트랙)

- **일반 던전 10종** — 특수아이템(아르카나/어비스) · 던전 히든 재료 파밍.
- **보스 던전 10종** — 제작 재료 · 보스 히든 · 스킬 진화 파밍.

### 던전 요구 스펙 (시트: `던전_요구치`)
각 던전은 2개의 기준선을 가진다.
- **요구데미지 min** = "딱 20분 클리어" 기준 = `(이전 티어 장비 풀셋 데미지) × 아르카나 풀스택(1.9)`
- **요구데미지 max** = "무조건 성공 & 최소시간" 기준 = `min × 2.5(하드클리어 배수)`
- 생존(방어+체력) 요구치도 동일 구조.
- **보스 던전**은 같은 단계 일반 던전 요구치 × **1.5**.

## 7. 전투 = 시간 측정 (시트: `시간곡선`)

직접 전투 없음. **내 데미지 ÷ 던전 요구데미지(20분 기준)** = **CPR(Clear Power Ratio)** 로 시간을 정한다.

```
CPR = MyDamage / ReqDamage_min(N)
ClearTime(분) = 시간곡선 룩업(CPR)     # 5분 ~ 20분, 티어 무관 공통 곡선
```

| 상황(현티어 아르카나) | CPR | 클리어 시간 |
|---|---|---|
| 이전티어 풀셋 입장 | 1.00 | 20분 |
| 아르카나 100 | 1.51 | 15분 |
| 아르카나 200 | 1.61 | 14분 |
| 아르카나 300 | 1.71 | 13분 |
| 아르카나 500 | 1.87 | 12분 |
| 아르카나 1000 | 2.11 | 10분 |
| 아르카나 2000 | 2.30 | 7분 |
| 아르카나 4000 | 2.50 | 5분 (하한) |

- **상한 20분 / 하한 5분.** (5분 = 모든 몹 처치 최소 시간)
- 위 표가 **정답 룩업**. 다른 티어 일반화/구현엔 연속 근사식 사용 가능:
  `T = clamp(5, 20, 20 − 11.35 × log2(CPR))`
- 이 곡선은 **티어 무관** (CPR이 정규화돼 있어서). 모든 던전에 같은 곡선 적용.

> 네가 준 예시("2던전, 1보스템 풀 + 1던전 알어풀 = 20분", "2던전 알어 100~4000 = 15/14/13/12/10/7/5")가
> 이 모델로 **그대로** 나온다. → 시트 `진행시뮬_2던전`에서 숫자 확인.

## 8. 성공 / 실패 판정 (시트: `성공확률`)

컷라인 근처면 실패가 섞이고, 스펙이 충분하면 무조건 성공.

```
p_dmg = clamp01( (내데미지 - 요구min) / (요구max - 요구min) )
p_sur = clamp01( (내방어+체력 - 생존min) / (생존max - 생존min) )
성공확률 = p_dmg × p_sur          # 둘 다 1.0 이면 100% 성공
```

| 케이스 | 데미지 위치 | 성공확률(예시) |
|---|---|---|
| 간신히 컷 (요구min ×1.05) | 컷 바로 위 | 약 3% |
| 어중간 (요구min ×1.6) | 중간 | 약 40% |
| 풀스펙 (요구max 이상) | 하드클리어 | 100% |

- 데미지만 높고 생존이 부족하면 `p_sur`가 낮아 실패 — **방어 장비도 맞춰야** 안정 클리어.
- 실패해도 시간은 소모(방치 페널티). 곡선 기울기는 `성공확률` 시트에서 튜닝.

## 9. 드랍 테이블 (시트: `드랍_조합`)

| 던전 | 항목 | 확률 | 1개 기대 런수 |
|---|---|---|---|
| 일반 | 특수아이템(아르카나/어비스) | 70% | 1.4런 (종류 절반이라 특정 타입은 2.9런) |
| 일반 | 히든 재료 | 1% | 100런 |
| 보스 | 제작 재료 | 3% | 33런 |
| 보스 | 히든 재료 | 1% | 100런 |
| 보스 3·6·9 | 스킬 진화 | 첫 클리어 시 획득(권장) | — |

- 특수아이템은 70%로 흔하지만 **4000개 풀스택은 장기 목표**(특정 타입 ~1.1만 런). 초반 100/200 구간은 금방 도달.

## 10. 조합법 (시트: `드랍_조합`)

- **무기 / 방어구 / 보조 / 모자 / 벨트** = 해당 단계 **보스 던전 재료**로 제작.
- **기타** = 해당 단계 **보스 히든 + 던전 히든** (히든 2종 요구 → 가장 희귀한 엔드 부위).

| 제작 부위 | 필요 재료 | 기대 런수 |
|---|---|---|
| 일반 장비 1칸 | 보스재료 5 | 약 167런 |
| 기타 1칸 | 보스히든 2 + 던전히든 2 | 약 400런 |

> 기대 런수가 과하면 `파라미터` 시트에서 **재료수↓** 또는 **드랍률↑** 으로 조절. (한 곳만 바꾸면 전체 반영)

## 12. 진행 흐름 예시 (시트: `진행시뮬_2던전`)

일반 2던전을 **2티어 장비 풀셋**으로 입장 → 아르카나를 모을수록:

| 아르카나 | 내 데미지 | CPR | 클리어 시간 |
|---|---|---|---|
| 0 (장비만) | 750 | 1.32 | (룩업 baseline 부근) |
| 100 | 862 | 1.51 | 15분 |
| 1000 | 1,200 | 2.11 | 10분 |
| 4000 | 1,425 | 2.50 | 5분 |

→ 4000 풀스택(데미지 1,425)이 **딱 3던전 20분 입장선**. 다음 던전은 장비를 3티어로 올려야 빨라짐 = 게이팅.

## 13. Unity 구현 메모

**데이터 (CSV / ScriptableObject):**
- `GearTier.csv` (티어별 스탯) ← 시트 `장비_티어`
- `SpecialStack.csv` (개수→배수) ← `특수아이템_스택`
- `TimeCurve.csv` (CPR→시간 룩업) ← `시간곡선`
- `DungeonReq.csv` (던전 요구치) ← `던전_요구치`
- `DropTable.csv`, `Recipe.csv` ← `드랍_조합`

**런타임 계산 순서(1런):**
1. `MyDamage = Σ(데미지장비) × 아르카나배수 × 스킬배수`
2. `MySurvive = Σ(방어장비 방어+체력)`
3. `CPR = MyDamage / ReqMin(N)` → `TimeCurve` 보간 → 클리어 시간
4. `성공확률 = p_dmg × p_sur` → 난수로 성공/실패
5. 성공 시 `DropTable` 굴려서 드랍 → 인벤토리 누적
6. 오토 종료 시 누적 드랍 정산 UI

**핵심 자료구조:**
```csharp
class CharacterState {
    int[] gearTier = new int[6];   // 부위별 장착 티어
    int specialCount;              // 아르카나/어비스 누적
    int skillEvolves;              // 0~3
}
```

## 14. 미해결 / 추가 튜닝 포인트

- **경험치/레벨 시스템**: 경험치 배수는 정의됨. 레벨이 스탯에 주는 영향은 미정 → 추가 설계 필요.
- **스킬 진화 드랍 방식**: 현재 "첫 클리어 100%" 가정. 확률 드랍으로 바꾸려면 파라미터 추가.
- **실패 페널티 강도**: 현재 시간만 소모. 재료 손실 등 추가 여부 결정 필요.
- **성공확률 곡선 기울기**: "간신히 3%"가 너무 짠지/적당한지 플레이 테스트로 조정.
- **두 캐릭터 시너지**: 동시 출전/교대 등 운용 규칙 미정.
```
